Geo No

Choose countries you don't want to watch YouTube Shorts or Instagram Reels from. Geo No checks each one as it appears and skips or hides it.

Countries to block

Countries marked ★ also get language, script and hashtag detection. All others are matched by the channel's declared country (YouTube API key, or an Instagram business address), tagged locations and #countryname hashtags.

Behaviour

Where to filter

Instagram Reels work on instagram.com/reels while you're logged in. No key needed.

When a Short or Reel matches

Skip jumps to the next one; Blur shows a card with an option to watch anyway.

Sensitivity

High catches more but may block some Shorts that aren't from your chosen countries.

YouTube API key (recommended for YouTube; not used for Instagram)

Without a key Geo No only sees each Short's title and channel name. With a free key it also reads the channel's country, description, tags and spoken language, which is much more accurate. The key stays in your browser.

  1. Open Google Cloud Console → YouTube Data API v3 and click Enable (create a project if asked).
  2. Go to Credentials → Create credentials → API key. In the "Create API key" form:
    • Name: anything (e.g. geo-no).
    • Select API restrictions: tick YouTube Data API v3 only. If it isn't in the list, step 1 wasn't done: enable it, then come back.
    • Application restrictions: leave on None. "Websites" would block the extension's own requests. Restricting the key to the YouTube API is protection enough: a leaked key can only use up your free YouTube quota.
    • Ignore the "Service account required" notice. It's only for Gemini / Agent Platform.
    Click Create and copy the key (starts with AIza).
  3. Paste it below and click Save & test. The free quota (10,000 units/day) covers roughly 5,000 Shorts a day.
