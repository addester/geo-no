YouTube API key (needed, free)

YouTube only lets apps list Shorts through its free Data API. Get your own key once and it stays on this device.

  1. Open YouTube Data API v3 in Google Cloud and tap Enable (create a project if asked).
  2. Open Credentials → Create credentials → API key. Under API restrictions tick YouTube Data API v3. Leave application restrictions on None.
  3. Copy the key (starts with AIza) and paste it here.
